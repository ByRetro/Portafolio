PROYECTO PERSONAL

SepulDev

Portafolio profesional desarrollado desde cero para presentar mis proyectos, habilidades y servicios como desarrollador. Diseñado con un enfoque minimalista, responsivo y centrado en una navegación clara.

HTML CSS JavaScript
Ver código

01

Objetivo

Crear un portafolio profesional desde cero para presentar mis proyectos, habilidades y servicios de forma clara, moderna y accesible.

02

Desarrollo

Construido utilizando HTML, CSS y JavaScript, trabajando tanto la estructura como el diseño y la interactividad sin utilizar una plantilla prediseñada.

03

Diseño

Interfaz minimalista con una identidad visual propia, una paleta basada en tonos turquesa y una navegación pensada para mantener una experiencia simple y fluida.

04

Características

Diseño responsivo, modo claro y oscuro, navegación dinámica con detección automática de secciones, menú hamburguesa para dispositivos móviles, tarjetas expandibles, animaciones e integración de un formulario de contacto mediante Formspree.

PROYECTO DEMOSTRATIVO

MONTIER

Tienda online demostrativa de moda masculina elegante, desarrollada con un catálogo interactivo, filtros por categoría, selección de tallas y consultas de disponibilidad vía WhatsApp.

HTML CSS JavaScript
Visitar sitio

01

Objetivo

Desarrollar una tienda online demostrativa de moda masculina elegante, ofreciendo una experiencia visual atractiva y una navegación sencilla para explorar sus productos.

02

Desarrollo

Proyecto construido desde cero utilizando HTML, CSS y JavaScript, implementando funcionalidades interactivas sin depender de frameworks externos.

03

Diseño

Interfaz minimalista inspirada en la moda masculina clásica, utilizando tonos crema, azul oscuro y una composición visual enfocada en destacar los productos.

04

Características

Catálogo interactivo, filtros por categoría, fichas detalladas de productos, selección dinámica de tallas, animaciones y consultas de disponibilidad mediante WhatsApp.
