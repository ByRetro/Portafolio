
# SepulDev

**Explore. Learn. Create.**

Portafolio profesional desarrollado desde cero para presentar
mis proyectos, habilidades y servicios como desarrollador web
y estudiante de Ingeniería en Informática.

## Características

- Diseño moderno y minimalista.
- Interfaz adaptable a dispositivos móviles.
- Modo claro y oscuro.
- Navegación dinámica entre secciones.
- Menú hamburguesa para dispositivos móviles.
- Tarjetas de proyectos expandibles.
- Animaciones y transiciones.
- Formulario de contacto integrado con Formspree.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Formspree

## Proyectos destacados

- **SepulDev:** portafolio profesional.
- **MONTIER:** sitio web demostrativo de una tienda de ropa elegante.

## Ejecución local

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Ejecutar index.html mediante Live Server.
